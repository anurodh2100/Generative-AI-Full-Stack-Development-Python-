## 📚 About the Course

This course provides a hands-on path from **Python fundamentals to modern AI engineering**, covering both the foundations and the systems used to build real-world AI applications.

### Topics Covered

* 🐍 Python Programming
* 🔀 Git & GitHub
* 🐳 Docker
* 🛡️ Pydantic
* 🧠 Large Language Models (LLMs)
* 🔤 Tokenization
* 🔢 Embeddings
* 👁️ Attention & Transformers
* ✍️ Prompt Engineering
* 🤖 AI Agents
* 📚 Retrieval-Augmented Generation (RAG)
* 🔗 LangChain
* 🕸️ LangGraph
* 💾 Vector Databases
* 🧠 AI Memory Systems
* 🎙️ Voice & Conversational AI
* 🖼️ Multi-Modal AI
* 🔌 Model Context Protocol (MCP)

The course also focuses on building, deploying, and scaling real-world AI applications rather than only learning theory.
